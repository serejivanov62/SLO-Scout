# SLO-Scout Build Guide

This document explains how to build and run the SLO-Scout project components.

## Quick Start

The project now includes automated build tools:

```bash
# Use the build script
./build.sh

# Or use Make
make build
make help  # See all available commands
```

## Prerequisites

- **Python 3.11+** with Poetry
- **Go 1.21+** for collectors
- **Java 11+** with Gradle for streaming jobs
- **Docker** (optional, for containerized builds)

## Component Overview

SLO-Scout consists of three main components:

1. **Python Backend** (FastAPI) - REST API and control plane
2. **Go Collectors** - High-performance telemetry ingestion
3. **Java Streaming Jobs** (Apache Flink) - Real-time analysis

## Building Components

### 1. Python Backend

The backend has two configuration modes:

**Minimal Mode (Recommended for dev/testing):**
```bash
cd backend
cp pyproject.minimal.toml pyproject.toml
poetry install --no-root
```

**Full Mode (For production with ML features):**
```bash
cd backend
cp pyproject.toml.full pyproject.toml  # If you switched to minimal
poetry install --no-root
```

**Run the backend:**
```bash
cd backend
poetry run uvicorn src.main:app --reload --host 0.0.0.0 --port 8000
```

Access API at: http://localhost:8000
API docs at: http://localhost:8000/docs

### 2. Go Collectors

**Important:** Building Go collectors requires:
- Network access to download dependencies (first build)
- `go.sum` file (generated by `go mod download`)

**Build all collectors:**
```bash
cd collectors

# Download dependencies (requires network access)
go mod download

# Build individual collectors
CGO_ENABLED=1 go build -o ../bin/prometheus-collector ./prometheus-collector/cmd
CGO_ENABLED=1 go build -o ../bin/otlp-collector ./otlp-collector/cmd
CGO_ENABLED=1 go build -o ../bin/log-collector ./log-collector/cmd
```

**Or use Make:**
```bash
make build-collectors
```

**Run a collector:**
```bash
./bin/prometheus-collector
# Configure via environment variables or config file
```

### 3. Flink Streaming Jobs

**Important:** Building streaming jobs requires network access to Maven Central.

**Build with Gradle:**
```bash
cd streaming
/opt/gradle/bin/gradle jar --no-daemon
```

The JAR will be created in `streaming/build/libs/slo-scout-streaming-1.0.0.jar`

**Or use Make:**
```bash
make build-streaming
```

## Docker Builds

Build Docker images for all components:

```bash
# Build all images
make docker-build

# Or build individually
make docker-build-backend
make docker-build-collectors
make docker-build-streaming
```

## Common Issues and Solutions

### Issue: No space left on device (Python backend)

**Solution:** Use minimal configuration or clean caches:
```bash
# Clean poetry cache
rm -rf /root/.cache/pypoetry
rm -rf backend/.venv

# Use minimal config
cd backend && cp pyproject.minimal.toml pyproject.toml
poetry install --no-root
```

### Issue: Go collectors fail with "missing go.sum entry"

**Solution:** Download Go dependencies (requires network):
```bash
cd collectors
go mod download  # Creates go.sum
go build ./...
```

### Issue: Gradle cannot download plugins/dependencies

**Solution:** This requires network access to Maven Central. Options:
1. Build in an environment with internet access
2. Use a local Maven repository/proxy
3. Pre-download dependencies in a Docker build

### Issue: Gradle wrapper not working

**Solution:** Use system Gradle or regenerate wrapper:
```bash
cd streaming
/opt/gradle/bin/gradle wrapper --gradle-version 8.5
./gradlew jar
```

## Development Workflow

### Quick Development Setup (No Network Required)

If you've already built once and have dependencies cached:

```bash
# Backend only (minimal deps)
cd backend
cp pyproject.minimal.toml pyproject.toml
poetry install --no-root
poetry run uvicorn src.main:app --reload
```

### Full Build with All Components

Requires network access for first-time setup:

```bash
# Run the automated build script
./build.sh

# Or step by step with Make
make clean
make build
make test
```

## Testing

```bash
# All tests
make test

# Individual component tests
make test-backend
make test-collectors
make test-streaming
```

## Deployment

For production deployment, use the Kubernetes Helm charts:

```bash
helm install slo-scout ./infrastructure/helm/slo-scout \
  --namespace slo-scout \
  --values infrastructure/helm/slo-scout/values-prod.yaml
```

See [README.md](README.md) for full deployment instructions.

## Architecture

```
├── backend/          # Python FastAPI application
│   ├── src/          # Source code
│   └── pyproject.toml # Dependencies
├── collectors/       # Go telemetry collectors
│   ├── common/       # Shared code
│   ├── prometheus-collector/
│   ├── otlp-collector/
│   └── log-collector/
├── streaming/        # Java Flink jobs
│   ├── fingerprinting-job/
│   └── embedding-pipeline-job/
└── infrastructure/   # Docker, Kubernetes, Helm
    ├── docker/
    └── helm/
```
